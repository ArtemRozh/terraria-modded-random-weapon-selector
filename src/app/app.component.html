If all you need is vanilla content, use this one, its better for that matter. If you find any inconsistencies, like weapons being in the wrong tier, or any other problem go to github page of this project Now to usage: If you roll on King Slime tier, the weapon you get is the one you would use untill you slay King Slime. Thats basic premise. Everything is up to the player anyway. It was made for Calamity mostly at first, but I removed anything related to it there. Though have plans in future to implement it with focus on infernum, depending on mods state, as currently it is ambigous what would really happen to Calamity. Weapons are located as early as they could be obtained. Bugs and niche methods aren`t accounted for. This site could support any amount of mods, only thing I need is mod data, which Im too lazy to gather due to requiring a lot of manual sorting. But its possible. If you dont like the progression, there should be a menu to modify it to fit your needs. Note that there could be some inconsistencies after some swaps. It is mostly made for bosses whose order is ambigous, mech bosses, etc. Its a bit poorly coded (as almost everything here) so it wont save after toggling mods, but it works
